## What was built

### `src/components/player/prefs.ts` (new, pure)

No React, no DOM, no `@/` imports. It answers:

- `authorDefaults(settings.accessibility)` returns what the tape asks for:
  - `highContrast: true` → `{ contrast: true }`
  - `dyslexiaFont: true` → `{ dyslexia: true }`
  - `false`, absent or non-boolean asks for nothing. `false` is the schema default.
- `resolve(authorDefaults, viewerChoices)` returns `{ prefs, source }`. It resolves field by field: the viewer's
  explicit choice, else the tape's default, else the product default. `source[field]` is `"viewer"`, `"author"`
  or `"default"`.
- `sanitize(stored)` reads the stored choices:
  - It takes the raw localStorage string or a parsed value.
  - **Sparse shape** (with `v`): every valid field is a choice.
  - **Legacy object** (no `v`): a value is a choice only where it differs from `DEFAULT_PREFS`.
  - Garbage gives `{}`.
  - The clamps are the shipped ones: timing 0.5–3, font scale 0.8–2.
- `toStored(choices)` returns `{ v: 2, ...only the touched fields }`.
- `pauseMultiplier(timingMultiplier, prefs)` returns the tape's `timingMultiplier` × the viewer's "Pause between
  pages" × the speed's pause factor. This is the arithmetic that shipped, moved here unchanged.
- Constants moved from the Player unchanged: `PREFS_KEY` (`"ssync-reader-prefs"`), `DEFAULT_PREFS`, `SPEED_PAUSE`
  and `SPEED_RATE`. New: `PREFS_VERSION = 2`.

### `src/components/player/Player.tsx`

- **Removed.** The in-file `Prefs`, `DEFAULT_PREFS`, the speed tables and `sanitizePrefs` are gone, and so is the
  effect that wrote the whole prefs object on every change. That effect also wrote on mount, so every visit wrote to
  storage.
- **State.** The Player now holds only `choices`, the viewer's explicit choices.
  - `prefs` and `source` come from `resolve(authorDefaults(settings.accessibility), choices)`.
  - The mount effect reads `sanitize(localStorage.getItem(PREFS_KEY))`.
  - `choose(patch)` is the only writer. It runs only when the viewer touches a control, and it writes
    `toStored(next)`.
- **Pauses.** `timingMult` comes from `pauseMultiplier(...)`.
- **Hint.** `SwitchRow` gains `fromStoryteller`. When the value's source is `"author"`, the switch shows
  "Set by the storyteller" (`data-pl="storyteller-default"`, 12 px, gold `#fbbf4a`) under its description.
- **Footer.** The Reading options sheet ends with a lock icon and "Saved on this device only"
  (`data-pl="prefs-local"`), in IBM Plex Mono, letter-spaced, muted. This is s02 figure C's footer, in sentence
  case.

## Deviations

- **Explicit `false` is not an author default.** Only `highContrast: true` / `dyslexiaFont: true` count as the
  storyteller asking. `false` is the schema default, so treating it as absent avoids a "Set by the storyteller" hint
  on a switch that is simply off. The effective value is the same either way. This is pinned in Node and stated in
  §4.
- **A broken `timingMultiplier` now means 1.** A non-number, non-finite, zero or negative value now reads as 1. Before,
  it was coerced or produced NaN, which made the hold collapse to the 300 ms floor. Every valid value (the schema's
  0.25–4, and any positive number) behaves exactly as before.
- **The hint is added, not swapped in.** "Set by the storyteller" is a second line under the switch's existing
  description, which still says what the switch does. It is not a replacement for that description. It is part of
  the switch's text, so a screen reader announces it with the switch.
- **A choice equal to the product default is still stored.** For example, `contrast:false` after turning a
  storyteller's HC off. That is what makes the choice win on the next HC tape.
- **`player.css` is outside my ownership.** I changed two declarations in the existing HC skin, for the reference's
  text treatment. No other file outside ownership was touched.

## Decision log entry

**2026-10-25 · T11 · `settings.accessibility` holds the storyteller's defaults; the viewer's own choices win, and only
those are stored.**

- **Where the answer lives.** `src/components/player/prefs.ts` is the one place that says how a page reads for this
  viewer.
  - It resolves field by field: the viewer's explicit choice, else the tape's default, else the product default.
  - Pure, relative imports only, so the Node tests import it.
- **What a tape can ask for.**
  - `highContrast: true` → high contrast.
  - `dyslexiaFont: true` → the easier-to-read font.
  - `false` is the schema default and is treated as absent.
  - `timingMultiplier` keeps its job: it scales every pause, and the viewer's pause and speed multiply on top. A
    broken multiplier reads as 1.
- **What is stored.**
  - Only choices the viewer actually made, under the unchanged key `ssync-reader-prefs`, in a sparse shape with a
    version marker: `{ "v": 2, "contrast": false }`.
  - On this device only, never sent anywhere (COPPA posture).
  - Opening a tape writes nothing. Before T11 the Player rewrote the whole prefs object on every mount.
- **Legacy entries.** A full object from before T11 counts as explicit only where a value differs from the product
  default. So the all-defaults object every old reader wrote means "no choices", and a stored `contrast: true` stays a
  choice. Legacy entries are not rewritten until the viewer changes a setting.
- **What the viewer sees.**
  - A switch whose value comes from the tape says "Set by the storyteller".
  - Turning it off is a choice that wins on every tape afterwards: "viewer preferences still win", s08 / HANDOFF §4.
  - The sheet's footer says "Saved on this device only" (s02 figure C).
- **The HC skin.** It is now pure white semibold, spoken words included, to match s02 figure C.
- **Spec.** `docs/format-spec.md` §4: "Players SHOULD apply `settings.accessibility` as defaults; a viewer's own
  choices override them, and are stored on the device only."
