# T09a · Expanded deck chip: three sounds and the narrator's name (evidence)

Milestone M2 · Reference: s02 (brief `screens[1]`) + s05 iPhone (brief `screens[4]`) · Status: **done**.
Every acceptance criterion has a test. There is one layout consequence beyond the ticket's letter: in spread mode the
book moves down to make room for the taller chip (see Deviations and the Decision log entry). `agent_docs/decisions.md`
is left to the commit step.

## What was built

### `src/components/player/deck-status.ts` (new, pure)
`deckStatus(page, manifest, flags, duckDepthDb)` returns `{ voice, melody, chime, foot, holdShare, speaking }`.
`formatCountdown(s)` returns ⌈s⌉ as m:ss. The flags are `narrating, paused, musicOn, musicLive, audioOk,
speechAvailable, holdRemainingS, holdTotalS` plus an optional `lastPage`. The mood comes from the shared `pageMood`
(`./music-plan`). The module reads only what it is handed: no storage, no counters.

| Row | Truth table (first match wins) |
|---|---|
| VOICE | recorded `audioUrl` → `VOICE · <metadata.narrator>` or `VOICE · Recorded voice` · no words → `VOICE · No words on this page` · speech → `VOICE · Storyteller (browser voice)` · else `VOICE · Words only` |
| MELODY | no Web Audio → `MELODY · no sound on this device` · listener off → `MELODY · off` · page names no music → `MELODY · none on this page` · bed live → `MELODY · <Mood>, <round(DUCK_DEPTH_DB)> dB under the voice` · bed not (yet) live → `MELODY · <Mood>` |
| CHIME | `pageTurnSound:false` → `CHIME · off` · `autoPlay:false` → `CHIME · when you turn the page` · paused → `CHIME · paused` · last page → `CHIME · last page` · speaking, or a voice still to come → `CHIME · after the voice` · otherwise → `CHIME · next turn in m:ss` |
| foot | `autoPlay:false` → none · last page → `the end in N s` · else `next page in N s · turn cue ready|off` (N = ⌈remaining⌉ during the hold, else ⌈the page's hold⌉) |

### `src/components/studio-kit/DeckChip.tsx` + `deck-chip.css` (new kit piece, brief design_system (7))
- **Root:** glass pill (radius 18, `rgba(8,11,21,.56)`, 1 px line, `blur(14px)`), `role="group"`,
  `aria-label="Now playing"`, `data-sk="deck-chip"`, `data-idle`, `data-live`.
  - The consumer passes `className` (the Player passes `pl-deck`) and `countClassName` (`pl-deck-read`).
  - It is never a live region.
- **Reels:** two kit `Reel`s with the sprite's paper faces and ink spokes, in a window.
  - They spin only while a voice speaks.
  - Under reduced motion they rest on the 18° frame (kit.css).
- **≥ 768 px (s02):**
  - left column: a dark 96×34 reel window with the tape line, over the 12 px mono counter;
  - then a hairline and three 11/14 mono rows. Each row's key (`<b>VOICE</b>`) is fg-3 at .12em; the value is fg-2.
  - Each row has a decorative `aria-hidden` 26×12 micro-glyph (`data-sk="deck-glyph"`):
    - the 9-bar waveform: static `rect`s, gold `#f5b544` while `speaking`, fg-4 otherwise;
    - three note dots with a down arrow;
    - a hollow ring.
- **< 768 px (s05):** the pill shows the reels, the counter, then the T03 group: `data-pl="deck-voice"` ⊃ hairline
  `deck-rule`, lucide Mic `deck-mic` 12 px gold, name `deck-narrator` 600 13 px white. The rows are `display:none`,
  so they are neither drawn nor announced. Below 360 px the pill gives back about 9 px so it clears the top chips at
  320.
- **Idle swap:**
  - When the room's chrome idles out, the rows fold away (`max-width` 0 + opacity 0, 320 ms). They stay inside the
    group for assistive tech.
  - At the same moment the narrator group opens. While the chrome is up, the group folds and the VOICE row says the
    name instead.
  - The reels and counter never hide. Reduced motion: no fold transitions.

### `src/components/player/deck.css` (new; the `.pl-deck*` block moved out of `player.css`)
- **Placement:** top-left, `top: max(14px, safe-area)`, `left: 16px`, z 20, `pointer-events: none`. From 768 px:
  `max-width: calc(100vw − 387px)`, which stops the chip 12 px short of the labelled top chips. A row that does not
  fit ends in an ellipsis.
- **Book clearance (spread mode):** the book's top edge moves to 98 px; its bottom stays 70 px off the floor. This
  is done through spread.css's own `--pl-spread-reserve-y` knob plus a re-centring `padding-top` on
  `.pl-page.is-spread/.is-single`.
- **Foot line:** `.pl-turn-foot` is a 24 px ring (`.pl-turn-track` + gold `.pl-turn-arc`) beside a mono 11 px line
  at .06em in fg-3.
  - Full motion: the arc fills in one `pl-turn-fill` pass across the hold, never a loop.
  - Reduced motion: the animation and transition are `none`, so the inline dashoffset, stepped once a second, jumps.

### `src/components/player/Player.tsx`
- The `.pl-deck` element is replaced by `<DeckChip>`. Its props are the page, total, `spinning`/`speaking`, the
  three rows from `deckStatus`, the narrator, and `idle = chromeHidden`.
- **Hold deadline**
  - `finish()` sets `hold = { page, until, totalMs }` alongside the turn timer it already scheduled.
  - The effect cleanup (turn, pause, end) clears it.
  - A hold whose `page ≠ index` is ignored, so nothing stale leaks onto the next page.
- **Tick:** one self-aligned timeout per second, only while a hold runs. It lands 15 ms after each whole second, so
  the deck reads 0:04 → 0:03 → 0:02 → 0:01 and the turn ends the last second.
- **Speech:** availability comes from `useSyncExternalStore`, so it is SSR-safe with no effect `setState`.
- **Hold length:** `pageHoldMs()` is shared by the timer and the display, so they cannot disagree.
- **Foot line:** `TurnRing` + `data-pl="turn-line"` sit in the book text page (spread and single), so the line is
  absent on phones and absent when `autoPlay` is false.

## Existing tests changed (`tests/vision-narrator.spec.ts`, T03), and why
1. `deck` `aria-hidden="true"` → `not aria-hidden` + `getByRole("group", { name: "Now playing" })` count 1.
   - Why: the ticket says so. The rows carry what nothing else states (the mood, the time to the turn).
2. `DECK_NON_REEL_SVG = svg:not(.sk-reel-svg)` (count 1 on Twinkle, 0 on the house tape) → `DECK_ICON_SVG =
   svg:not(.sk-reel-svg):not([data-sk="deck-glyph"])` with the **same counts**.
   - Why: the ticket's re-target, because the rows' micro-glyphs are SVG too.
   - The original strength is kept: the mic is still the only icon.
3. House tape `deck` `toHaveText(/^01 / 08$/)` ("only the page counter") → counter `.pl-deck-read` has text
   "01 / 08", and `deck-voice` and `deck-narrator` both have count 0.
   - Why: the reference deliberately adds the three rows' text to the chip, so the chip's whole text is no longer just
     the counter.
   - The intent (a counter and no name) is unchanged.

No test was skipped or deleted. The T08 spread tests are untouched and green (see Deviations for the geometry they now
measure). `fable-pass` is green: the chip adds no `data-page`. `critic-landing` "packed tape really plays" is green.

## Deviations from the reference, and why
1. **No pack discs on the reels** (expected): they arrive in T09b. The reel window is 34 px tall instead of 42, which
   leaves room for the packs.
2. **The violet "Next" chip** on the reference deck is reel annotation, not UI (expected). Not built.
3. **CHIME and the read-along cannot both be lit at once.** The reference shows "cats" lit *and* "next turn in 0:03".
   The app tells the truth: while a voice speaks the chime row says "after the voice" and the ring is empty. The
   countdown and the arc run during the hold. Both states are captured (`T09a.png`, `T09a-hold.png`).
4. **Chip height 67 px (reference 81) and book top 98 px.**
   - The conflict: T08 put the book at y 70 (brief), but the reference render's chip ends at y 97 and the render's
     book starts at y 116. T08's own test forbids the book under the chip.
   - The fix: deck.css moves the book's top to 98 px in spread mode. The bottom stays 70 px off the floor, so it is
     still clear of the transport.
   - The chip is trimmed to 67 px. With T08's "book ≥ 75 % of the viewport height" rule (525 px at 700) this leaves
     17 px of air between them.
   - Result at 1120×700: book 950×532 at (85,98), previously 1000×560 at (60,70).
   - Art share 0.56, centring, square art, prose at 24.7 px (T08's 24–28 band) and all T08 assertions hold.
5. **768 to about 850 px wide** (tablet portrait): the labelled top chips (~345 px) leave the chip ~380 px, so
   "VOICE · Storyteller (brows…" and "MELODY · Wonder, 12 dB und…" are ellipsized. The full text stays in the group
   for assistive tech. From about 850 px nothing is cut.
6. **The chip is always at full opacity.** The shipped deck dimmed to .55 when not speaking; that would put the
   11 px rows below a readable contrast.
7. **Two states the reference does not show**, worded plainly:
   - On the last page the automatic end opens the end card **without** a chime (the Player calls `setEnded`
     directly), so CHIME says "last page" and the foot says "the end in N s" instead of promising a turn and a cue.
   - A bed that is not live yet says "MELODY · <Mood>" with no dB claim.

## Decision log entry
**2026-10-26 · T09a · The deck chip states the three sounds; the book makes room for it.**
- **Rows:** from 768 px the Player's deck chip (kit `DeckChip`) is a `role="group"` named "Now playing" with three
  mono rows. Their words come from one pure module, `src/components/player/deck-status.ts`, which reads the manifest
  and live flags only. The MELODY number is `round(DUCK_DEPTH_DB)` from the engine, never a literal.
- **Countdown:** it ticks once a second, only during the hold the Player already schedules, and is never `aria-live`.
- **Whose voice:** the name is shown exactly once at any time. While the chrome is up, the VOICE row names the
  narrator (≥ 768); when the chrome idles out, the rows fold and T03's mic + name opens. This is now the rule at
  every width; T03 previously kept the name always open at ≥ md.
- **Book clearance:** in spread mode the book's top edge moves to 98 px. `deck.css` overrides spread.css's
  `--pl-spread-reserve-y` and re-centres with `padding-top`. The book is 950×532 at 1120×700 (was 1000×560), the
  render's chip-above-book composition, with T08's ≥ 75 % vh and centring rules intact.
- **Last page:** CHIME reads "last page" and the foot "the end in N s", because the automatic end does not chime.
- **Open question for Jon:** should the automatic end chime like a manual "next" on the last page does?
