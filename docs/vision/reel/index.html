The feeling

A picture, a voice, a melody, a chime

The kid at the library table with a book and a cassette. Every screen protects that undivided attention: the room recedes and the story glows.

The loop

Receive a story, then make one back

Every tape ends with an invitation to make your own. Grandma listens, then answers in her own voice. That loop is the reason the format exists.

The promise

Nothing leaves without a grown-up

A parent's gate before anything is shared, consent written into the file, one tap to delete every copy, unlisted links, and no trackers anywhere.

The format

One open file outlives the app

SSYNC packs seven layers into one ZIP. Voices are always AAC, so a tape made on an Android tablet plays on an iPhone, and anyone can write a player.

The SSYNC protocol · version 2.0

One file holds the whole storybook.

SSYNC is to storybooks what PDF is to documents: pictures, words, voices, music and timing in one open file. Deliberately not video. The player is plain web — nobody needs our servers, or our app, to hear a story.

The codec rule
  • MUSTNarration is AAC-LC in M4A, mono, 48 kHz, about 96 kbps.
  • MAYFall back to 16-bit WAV, 16 kHz mono. The only fallback.
  • MUST NOTOpus, WebM or Ogg. Drafts only, never a published tape.
Validator
  1. PASSversion 2.0 · metadata.title · 5 pages
  2. PASSevery assets/ path in the manifest exists
  3. WARNsignature.voiceConsent[0].date is a full timestamp; the v2.1 draft asks for a date
  4. FAILa hand-edited copy: pages[2].text.audioUrl 'assets/narration-3.webm' uses a draft-only codec — published narration must be AAC/M4A (or WAV fallback)
Write your own player
import { unzipSync, strFromU8 } from 'fflate';
const files = unzipSync(tape);
const m = JSON.parse(strFromU8(files['manifest.json']));
for (const page of m.pages) {
  draw(files[page.illustration.url], page.text.content);
}

How it fits together

One tape, every surface

The Creator writes one manifest. The grown-up gate signs it, voices become AAC, and it travels as a link, a QR code or a .storysync file. The Reader plays that same manifest on any device, and its last page invites you to make one back. Nothing leaves a device before the gate, consent travels inside the file, and deleting removes every copy.
