The SSYNC protocol · version 2.0

One file holds the whole storybook.

SSYNC is to storybooks what PDF is to documents: pictures, words, voices, music and timing in one open file. Deliberately not video. The player is plain web — nobody needs our servers, or our app, to hear a story.

The codec rule
  • MUSTNarration is AAC-LC in M4A, mono, 48 kHz, about 96 kbps.
  • MAYFall back to 16-bit WAV, 16 kHz mono. The only fallback.
  • MUST NOTOpus, WebM or Ogg. Drafts only, never a published tape.
Validator
  1. PASSversion 2.0 · metadata.title · 5 pages
  2. PASSevery assets/ path in the manifest exists
  3. WARNsignature.voiceConsent[0].date is a full timestamp; the v2.1 draft asks for a date
  4. FAILa hand-edited copy: pages[2].text.audioUrl 'assets/narration-3.webm' uses a draft-only codec — published narration must be AAC/M4A (or WAV fallback)
Write your own player
import { unzipSync, strFromU8 } from 'fflate';
const files = unzipSync(tape);
const m = JSON.parse(strFromU8(files['manifest.json']));
for (const page of m.pages) {
  draw(files[page.illustration.url], page.text.content);
}

Like PDF, for storybooksA .storysync is a ZIP: manifest.json plus assets/. Rename it .zip and open it with anything; drop it on the Reader and it plays.
Layers add sensesOnly metadata.title is required. Marco's e-reader draws layers 1–3, picture and words, and Mia's tape still works.
Privacy is in the specA grown-up gate before anything leaves a device, delete means all of it, zero trackers in any player, unlisted links: the format's own rules, not a policy page.
The rule behind the grandparent momentPublished narration is AAC/M4A, WAV is the only fallback, Opus never ships. It is why an Android recording plays on an iPhone.
