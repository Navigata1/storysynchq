## New findings
- **K52 (High):** the "enforced" layer can be removed in the same PR that weakens a judge. The PR's own `ci.yml` drops the `frozen.py` and `registered.py` steps (or keeps a job named `verify` that does nothing), the `verify` check-run is green, and `merged_scan` accepts it.
- **K53 (Medium):** what `frozen.py` accepts as an amendment is any added `contract.md` line containing the path. The lead writes that line, and the contract can also lose lines unchecked. So it enforces that a judge change is visible, not that it is prevented.
- **K54 (Medium):** this seat has more than Read, Grep and Glob. Its tool list includes Artifact (publishes to claude.ai), Workflow (spawns agents), SendUserFile, ListAgents and SendMessage (deferred; these reach other local Claude sessions, the lead's among them), CronCreate, PushNotification and EnterWorktree. I did not use any of them. The preflight tests only Read, Glob and a shell.
- **K55 (Medium):** the journey's "narration heard" check counts `play()` calls. The Player's `el.onerror = () => finish()` moves to the next page on audio that will not decode. So a published tape with broken narration still reaches the end card and passes C1.
- **K56 (Low):** squash and rebase merges pass `merged_scan`, but after one, `review_closed` fails at every later head because the reviewed head is not an ancestor of HEAD. No merge method is fixed anywhere.
- **K57 (Medium):** a direct push to main is never scanned. `merged_scan` lists PRs only, and the lead holds the operator's (admin) token.
- **K58 (Low):** `test_gates.py` has no fixture for `registered.py`, although plan-readiness says completeness was "proved with a planted stray file".
